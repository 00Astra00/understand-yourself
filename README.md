# understand yourself

一套用于「认识自己、理清问题、学习、决策」的提示词 Skill。全文收录 5 个场景、12 个提示词，直接调用即可。

## 包含什么

| 场景 | 提示词 | 解决什么 |
|---|---|---|
| 一. 问清问题 | 苏格拉底式提问 | 找到真正值得回答的问题 |
| 二. 学习 | 双层解释法 | 从生活化理解推进到专业机制 |
| 二. 学习 | 反向拆解 | 从优秀成品中提炼可迁移规律 |
| 二. 学习 | 横纵分析法 | 系统研究陌生产品、公司、行业 |
| 二. 学习 | 事实核查 | 判断说法真假、推理是否成立 |
| 三. 解决问题 | 专家会诊 | 三种互补视角互相质疑后给方案 |
| 三. 解决问题 | 第一性原理 | 抛开惯例，从基本事实重新推导 |
| 三. 解决问题 | 跨领域借解 | 从其他领域借用成熟机制 |
| 四. 决策 | 双向钢人论证 | 两个选项都强化后，再判断 |
| 四. 决策 | 用最小实验替代空想 | 低成本、可逆地验证关键假设 |
| 五. 认识你自己 | 挖掘隐藏天赋 | 从经历、能量、阴影和嫉妒里找天赋 |
| 五. 认识你自己 | 人生设计术 | 生成三个五年版本和原型行动 |

## 怎么用

1. 直接说出需求，例如：「用苏格拉底式提问帮我理清要不要换工作」。
2. 或点名提示词，例如：「用人生设计术」。
3. 把【】里的占位内容换成自己的信息；有文档、网页、数据就一起提供。
4. 长流程（天赋挖掘、人生设计）通常需要多轮对话，回答越具体，结果越有用。

## 输出形态

- 苏格拉底问诊：问题定义 + 事实 / 假设 / 关键变量清单
- 双层解释：小白版 + 专业版 + 理解检查题
- 事实核查：可信度分级 + 推理漏洞 + 修正版
- 决策：明确判断 + 适用条件 + 第一步行动
- 天赋挖掘：约一万字《个人天赋使用说明书》
- 人生设计：8000–12000 字《个人人生设计蓝图》

## 设计原则

一次只问一个问题；判断绑定具体经历；区分事实、解释与价值判断；区分「擅长」与「回血」；不做空泛赞美；不替用户做人生决定；所有长线建议都落到低成本、可逆的下一步。
